Selected work

Logility

2024–2026

Moved 3,000+ help topics from RoboHelp to Markdown and Git

Logility's help content had lived in a single-writer RoboHelp workflow, shipped as emailed PDFs, for a decade. As the sole technical writer, I converted 15 products' worth of topics with Pandoc scripts and replaced that workflow with in-product help built from a Git repository.

  • Seven development teams submitted documentation changes as pull requests, which I reviewed and approved.
  • GitHub Actions built and published each change after approval.
  • I wrote the contribution guidelines, style guide, templates, and change criteria that made the model work.

NBCUniversal

2026, contract

Built a knowledge governance program for Workplace Operations

I set the documentation standards and ownership structure for TechOps knowledge in ServiceNow and SharePoint, including a Knowledge Owner program that assigns accountability for keeping content current.

  • Defined SOP and knowledge base article standards and templates.
  • Audited existing processes and reworked the information architecture.
  • Helped shape the backend prompts for an AI knowledge assistant drawing on that content.
